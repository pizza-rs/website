Robust Share-nothing Architecture
Complete resource isolation at the node and per-CPU level. Fully asynchronous I/O, written in Rust for many-core CPUs, large memory and NVMe SSD.
Features
Our mission is to deliver real-time, intelligent search using modern hardware and AI.
To infinity scaling!
Pizza does things differently!

Collections are partitioned into fixed-capacity rollings that cut over automatically — keep writing and grow from zero to petabytes without pre-sizing shards or reindexing. Need more shards anyway? Reshard online, while every read and write keeps being served.
Experience True Real-Time Search
Results appear the moment a write is acknowledged — there is no refresh cycle and no near-real-time window. A crash-safe write-ahead log backs every write with configurable durability. Index new content and query it in the same breath, always up to the second.
Efficient In-Place Partial Updates
Update a single field without pulling and pushing the whole document back. In-place columns write in O(1) on a fast lane, and operator lists (incr, append, rename…) apply atomically under optimistic concurrency. Keep thousands of fields fresh at a fraction of the usual cost.
Hybrid Search, One Query
Full-text BM25, vector kNN, semantic, graph traversal, geo and structured filters — combined in a single query with RRF or linear fusion. Common Elasticsearch syntax works as-is.
High Performance
A lightning-fast Rust engine with exceptional throughput and minimal latency — squeezing the most out of modern hardware, with fewer machines.
One Engine, Anywhere
The same core runs as a distributed cluster, a single binary, or WebAssembly in your browser. Storage and compute are separated by design.
AI-Native Innovation
Map a field with a model and queries turn semantic: vectors are derived at write time via OpenAI-compatible embeddings — plain text in, relevant results out.
