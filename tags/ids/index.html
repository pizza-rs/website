IDs query

/ Ids, / Query

IDs query #

Returns documents whose id is in the provided set. There is no field argument — the match is against the document identity itself, and values that do not exist in the collection are skipped.

On Pizza server the same mixed-id convention as GET/DELETE/UPDATE applies to every value: a value containing a comma ("0,17") addresses a document by its system id (rolling,seq — the same id hits echo as _id); any other value is a user key. Query and response therefore speak the same ids both ways.
